# Scenario Data

`country_scenarios.csv` contains **illustrative starting assumptions**, not live observations or forecasts. The values make it easier to open the dashboard and compare model behaviour immediately.

For empirical work, replace them with a dated and cited dataset. Record:

- the exact FX convention (local currency per USD);
- observation date and frequency;
- source series or API identifier;
- whether the rate is official, market, or parallel-market; and
- any transformations applied before simulation.

Recommended sources include central-bank releases, FRED, the World Bank, and IMF datasets, subject to their respective terms and methodological limitations.
